Quick start
  1. Pick an original course or switch to Installed maps to edit Hood Corner, Tree Land, and other packages already in the plugin folder.
  2. Choose Edit course to change a layout or New layout to start a variation on that map.
  3. Drag tee and basket markers, then use the right panel for par, shot limit, OB, and cards.
  4. Click Export to game, then restart the game to load the saved course.
